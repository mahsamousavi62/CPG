## 25 Audit Log Parameters

### Core Parameters (1-7)
1. **log_id**: Unique identifier (auto-generated by Elasticsearch)
2. **timestamp**: Event timestamp (ISO 8601 format)
3. **audit_level**: Log level (info, warn, error, fatal)
4. **audit_type**: Type of audit (client, provider, user, develop)
5. **correlation_id**: Request correlation across services
6. **request_id**: Unique identifier for this specific request
7. **service_name**: Name of the service/endpoint

### User Context (8-11)
8. **user_id**: Authenticated user ID
9. **company_id**: Company/merchant ID
10. **application_id**: OAuth application ID
11. **client_id**: OAuth client identifier

### Request Context (12-17)
12. **user_agent**: Client user agent string
13. **client_ip**: Client IP address
14. **http_method**: HTTP method (GET, POST, etc.)
15. **endpoint_url**: Full endpoint URL
16. **query_params**: Query string parameters
17. **request_body**: Request payload (sanitized)

### Response Context (18-19)
18. **response_status**: HTTP status code
19. **response_body**: Response payload (sanitized)

### Performance & Error (20-25)
20. **start_time**: Request start timestamp
21. **end_time**: Request end timestamp
22. **duration_ms**: Duration in milliseconds
23. **is_success**: Boolean success indicator
24. **error_code**: Error code (if applicable)
25. **stack_trace**: Stack trace (for errors)
